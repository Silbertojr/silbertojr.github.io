Política de Privacidade

Atualizada em 25 de novembro de 2026.

O minha-fabrica é uma ferramenta pessoal. Ela roda só no computador do dono e serve para publicar os vídeos dos canais dele no YouTube.

O que a ferramenta acessa

Ela usa a YouTube Data API v3 com duas permissões:

  • youtube.upload: para enviar vídeos.
  • youtube.force-ssl: para colocar a capa e agendar a publicação de vídeos.

Ela lê o nome e o endereço do canal para saber em qual canal vai publicar.

Onde os dados ficam

A autorização do Google fica guardada só no computador do dono. Nenhum dado é enviado para servidores próprios, vendido ou compartilhado com terceiros. Os dados só vão para o Google, pela API do YouTube.

Como retirar o acesso

Você pode retirar o acesso a qualquer momento em myaccount.google.com/permissions.

Serviços do Google

Ao usar esta ferramenta você também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Contato

Fale com o dono pelo canal Doña Carmiña no YouTube ou pelo e-mail de suporte que aparece na tela de autorização do Google.
